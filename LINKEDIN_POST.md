# LinkedIn Post

I built **AegisAI**, a reproducible AI security framework that tests how language and vision models handle untrusted instructions hidden in text and images.

The project includes:

- Prompt-injection attack and defense scenarios
- AI-agent trust-boundary testing
- LLM and multimodal model evaluation
- CPU-based image testing for ordinary laptops, without requiring a GPU
- Measurable results for detection, bypasses, errors, confidence, and latency
- Clear HTML, Markdown, PDF, DOCX, and PowerPoint reports

The goal is simple: help AI systems treat external content as evidence, not as an instruction to follow.

I built this project to explore AI engineering, LLM evaluation, multimodal security, prompt engineering, and responsible AI research.
